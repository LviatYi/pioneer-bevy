# 地形 Terrain

为满足玩家的 [核心体验](../../README.md)，地形系统计划这样实现：

## [地貌 Landform](../../docs/design/landform.md)

地貌描述地表的形态特征，包括山脉、丘陵、平原、洞穴等。

体验目标在于地貌多样性，具备丰富的地形类型和变化。因此应采用接受可插入式的地貌生成算法的实现方案。

MVP 地貌算法将提供一个平坦算法。

### 当前初步实现

- `LandformSample` 作为可插拔的三维标量场接口，默认使用地表高度为 `y = 0` 的 `FlatLandform`。
- 以 `1m` 间距在 `16³` Cell 的三维 Chunk 中采样，相邻 Chunk 的采样位置由整数坐标统一推导。
- `TerrainChunkCache` 缓存已调度 Chunk 的 `17³`（边缘 Chunk 除外）采样值。
- 使用 Marching Cubes 提取零等值面，并生成带索引和法线的独立 Chunk Mesh。
- 当前只调度覆盖有限地图 XZ 范围、位于 `y = 0` 上下各一层的 Chunk；尚未实现随玩家移动的流式调度、玩家修改叠加和碰撞体生成。

## 地质 Geology

地质描述星球内部的结构和组成，包括矿脉、岩层等。

生成结果将收到：地质群系（矿脉特点）、高度的影响。

## 玩家交互 User Interaction

玩家可以通过建造、挖掘等方式改变地形。

### 建造 Building

建筑位置依托于网格。而地形则是连续的。建筑在生成时会与地形出现矛盾。

- 建筑可能部分悬空。应避免出现这种情况。
- 地形可能与建筑重叠（穿模入建筑内部）。应避免出现这种情况。

### 挖掘 Digging

允许玩家挖掘、铲平来改造地形。
